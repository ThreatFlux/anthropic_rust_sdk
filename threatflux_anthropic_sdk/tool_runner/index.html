Module tool_runner 

Source
Expand description

Optional, bounded execution of explicitly registered client tools.

Callbacks run only after a complete Messages response (or terminal SSE collection), never from partial input JSON. Tool results contain strings or supported content blocks; arbitrary JSON is encoded as text. See Anthropic’s tool-runner workflow, verified 2026-10-03. This community runner has its own explicit safety budgets and does not claim every official SDK convenience.
