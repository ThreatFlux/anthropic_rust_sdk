Common data types shared across API models.

Content and usage schemas were verified 2026-10-03 against Anthropic’s stable content parameters and beta response blocks. Unknown objects round-trip unchanged; known optional null/missing fields may normalize to omission, and nullable cache counters normalize to zero.
